# HM 关节伺服 PCAN 调参工具

依据《HM系列关节伺服电机使用手册V1.06》编写，适配 PEAK PCAN-USB，默认量程按 HM9816G9 (G9)。

## 安装 / 运行
```
pip install -r requirements.txt
python main.py          # 真实硬件（需安装 PEAK 驱动，PCANBasic.dll）
python main.py --sim    # 仿真总线（虚拟电机 ID 1 和 5），无硬件体验全部功能
python -m pytest tests  # 单元/集成测试
```

## 功能
- **MIT 控制**：使能(FC)/失能(FD)/清错(FB)/设零(FE)，p/v/kp/kd/t 滑条，快捷模式（阻尼/速度/位置/扭矩），发送频率 50–1000 Hz。
- **实时曲线**：位置/速度/扭矩（指令 vs 反馈）与温度，暂停、时间窗口、CSV 导出。
- **参数寄存器**：全部读取、编辑后写入、保存 Flash（仅失能时）、修改 ID、JSON 导入导出。
  连接后自动读取 p_max/v_max/t_max 更新 MIT 量程。
- **测试信号**：阶跃/方波/正弦/扫频，作用于 p/v/t，自动录制，输出上升时间/超调/调节时间/稳态误差。
- **扫描/报文**：逐个 ID 发 0xCC 查询发现电机；原始帧日志（带解析注释、过滤、保存）；手动发送任意帧。

## 安全
- **Esc / 空格 = 急停**（发零力矩帧 + 失能）；空格在输入框内不触发。
- 使能时目标位置自动取当前位置，kp=0、kd=0.5。
- 使能中禁止保存 Flash、改 ID、设零、扫描；断开/关闭窗口自动发失能。
- 反馈超过 200 ms 未到、错误码非 0 时状态栏标红。
